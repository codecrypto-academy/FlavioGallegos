Ejercicio 1 : NGINX EN DOCKER CON DOCKER COMPOSE
objetivos:
- Crear un entorno de desarrollo con Docker compose
- Servir una pagina HTML PERSONALIZADA
- Entender el ciclo de vida de los contenedores con compose
 
REQUISITOS PREVIOS:
- Dockerd Desktop instalado y ejecutandose
- Terminal // Command Prompt o PowerShell

Pasos
    1.- Crear la estructura de directorios
    2.- Crear el archivo HTML 
    3.- Crear el archivo docker compose.yml
    4.- Iniciar el servicio con docker compose up 
    5.- Verificar el funcionamiento con el navegador
    6.- Ver los logs
    7.- Administrar el servicio Iniciar/Detener el servicio
    8.- Verificar la recarga en caliente
    9.- Limpiar el entorno
