# Calculadora Básica

Una calculadora básica implementada con HTML, Tailwind CSS y TypeScript.

## Características

- Operaciones básicas: suma, resta, multiplicación y división
- Interfaz moderna y responsive con Tailwind CSS
- Implementación en TypeScript con tipado estricto
- Manejo de errores (división por cero, números muy largos)

## Instalación

1. Instalar dependencias:
```bash
npm install
```

2. Compilar TypeScript:
```bash
npm run build
```

O para compilar en modo watch (automático):
```bash
npm run watch
```

## Uso

Simplemente abre el archivo `index.html` en tu navegador. Asegúrate de que el archivo `calculator.js` esté generado (compilado desde `calculator.ts`).

## Estructura del Proyecto

- `index.html` - Estructura HTML de la calculadora
- `calculator.ts` - Lógica de la calculadora en TypeScript
- `calculator.js` - Archivo JavaScript compilado (generado)
- `tsconfig.json` - Configuración de TypeScript
- `package.json` - Dependencias del proyecto
